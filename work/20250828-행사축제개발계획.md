# K-Tour 행사/축제 화면 개발 계획

## 📋 개발 목표
한국관광공사 Tour API의 행사/축제(`contentTypeId=15`) 데이터를 활용한 종합적인 행사/축제 탐색 및 관리 화면 개발

## 🔍 현황 분석

### 기존 구현 현황
- **엔티티**: `TourFestival` 모델 구현 완료 (freezed)
  - 축제 상태 (예정/진행중/종료)
  - D-Day 계산 기능
  - 날짜 포맷팅 기능
- **API**: `searchFestival` 메서드 구현 완료 (TourAPIDataSource)
- **메인화면**: 진행중인 축제 섹션 표시 중
- **아키텍처**: Clean Architecture 적용

## 💡 구현 예시 코드

### FestivalState 구조
```dart
@freezed
class FestivalState with _$FestivalState {
  const factory FestivalState({
    @Default([]) List<TourFestival> festivals,
    @Default(true) bool isLoading,
    String? error,
    FestivalStatus? filterStatus,
    String? filterAreaCode,
    DateTime? filterMonth,
    @Default('R') String sortBy, // R=시작일순, O=제목순
    @Default(1) int currentPage,
    @Default(false) bool hasMore,
  }) = _FestivalState;
}
```

### API 호출 예시
```dart
Future<void> loadFestivals() async {
  state = state.copyWith(isLoading: true, error: null);
  
  try {
    final now = DateTime.now();
    final startDate = DateFormat('yyyyMMdd').format(
      state.filterMonth ?? now.subtract(Duration(days: 30))
    );
    final endDate = DateFormat('yyyyMMdd').format(
      state.filterMonth?.add(Duration(days: 30)) ?? 
      now.add(Duration(days: 365))
    );
    
    final festivals = await repository.searchFestivals(
      eventStartDate: startDate,
      eventEndDate: endDate,
      areaCode: state.filterAreaCode,
      arrange: state.sortBy,
      pageNo: state.currentPage,
    );
    
    // 상태별 필터링
    final filtered = _filterByStatus(festivals);
    
    state = state.copyWith(
      festivals: filtered,
      isLoading: false,
      hasMore: festivals.length == 20,
    );
  } catch (e) {
    state = state.copyWith(
      isLoading: false,
      error: e.toString(),
    );
  }
}
```
