## 2. 버그 수정

### 2.1 Supabase UUID 타입 오류 해결
#### 문제
- `heritage_image` 테이블의 `id` 필드가 UUID 타입으로 설정되어 있었음
- 앱에서는 문자열 형식 ID 사용 (예: "11_0002290000000_11_placeholder")
- PostgrestException: invalid input syntax for type uuid 오류 발생

#### 해결
```sql
-- heritage_image 테이블의 id 컬럼 타입을 UUID에서 TEXT로 변경
ALTER TABLE heritage_image 
ALTER COLUMN id TYPE TEXT,
ALTER COLUMN id DROP DEFAULT;

-- heritage 테이블에 mainImageUrl 필드 추가
ALTER TABLE heritage 
ADD COLUMN IF NOT EXISTS main_image_url TEXT;
```

### 2.2 Provider 수정 타이밍 오류 해결
#### 문제
- Widget 빌드 중 Provider 수정 시도로 인한 오류

#### 해결
```dart
@override
void initState() {
  super.initState();
  // WidgetsBinding을 사용하여 빌드 완료 후 실행
  WidgetsBinding.instance.addPostFrameCallback((_) {
    _loadHeritageDetail();
  });
}
```

## 3. 데이터 저장 이슈 분석

### 3.1 현황
- API에서 600개 문화재 데이터 fetch (서울 200, 경기 200, 인천 200)
- Supabase에는 19개만 저장됨

### 3.2 원인 분석
1. **좌표 필터링**: `lat: 0.0, lng: 0.0`인 데이터 제외 (약 30-40%)
2. **거리 제한**: 현재 위치 3km 반경 내 데이터만 저장
3. **국보 특성**: 전국 분산되어 있어 대부분 필터링됨

### 3.3 코드 위치
```dart
// heritage_repository_impl.dart 172-185줄
final nearbyHeritages = allHeritages.where((heritage) {
  if (heritage.latitude == 0 || heritage.longitude == 0) return false;
  if (heritage.latitude < 33 || heritage.latitude > 39) return false;
  if (heritage.longitude < 124 || heritage.longitude > 132) return false;
  
  final distance = _calculateDistance(...);
  return distance <= radiusKm;  // 기본 3km
}).toList();
```
