## 구현 내용

### 1. Supabase 데이터베이스 구축

#### 1.1 테이블 스키마 생성
```sql
-- PostGIS 확장 활성화 (위치 기반 쿼리)
CREATE EXTENSION IF NOT EXISTS postgis;

-- heritage 테이블: 문화재 기본 정보
CREATE TABLE heritage (
    id TEXT PRIMARY KEY,
    kdcd TEXT NOT NULL,        -- 종목코드
    ctcd TEXT NOT NULL,        -- 시도코드
    asno TEXT NOT NULL,        -- 관리번호
    name_ko TEXT NOT NULL,     -- 한국어 명칭
    name_hanja TEXT,           -- 한자 명칭
    name_en/ja/zh TEXT,        -- 다국어 명칭
    category TEXT NOT NULL,     -- 종목명
    latitude/longitude DOUBLE, -- 좌표
    location GEOGRAPHY(Point), -- PostGIS 지리 타입
    address TEXT,              -- 주소
    period TEXT,               -- 시대
    designated_date DATE,      -- 지정일
    description_ko/en/ja/zh TEXT, -- 다국어 설명
    admin TEXT                 -- 관리기관
);

-- heritage_image 테이블: 문화재 이미지
CREATE TABLE heritage_image (
    id UUID PRIMARY KEY,
    heritage_id TEXT REFERENCES heritage(id),
    image_url TEXT NOT NULL,
    thumbnail_url TEXT,
    description TEXT,
    copyright TEXT,
    display_order INTEGER
);

-- translation_cache 테이블: 번역 캐시
CREATE TABLE translation_cache (
    id UUID PRIMARY KEY,
    src_lang TEXT,
    dst_lang TEXT,
    src_text TEXT,
    src_text_hash TEXT,
    dst_text TEXT
);
```

#### 1.2 위치 기반 검색 함수
```sql
CREATE OR REPLACE FUNCTION get_nearby_heritages(
    user_lat DOUBLE PRECISION,

RETURNS TABLE (
    id TEXT,
    name_ko TEXT,
    category TEXT,
    address TEXT,
    latitude DOUBLE PRECISION,
    longitude DOUBLE PRECISION,
    distance_km DOUBLE PRECISION
)
```

## 주요 기능

### 실행 흐름
1. 앱 시작 시 `HeritageController` 초기화
2. 위치 권한 확인 및 요청
3. 현재 위치 기반 주변 문화재 조회
   - Local DB 확인 → 없으면 Remote API 호출 → 캐싱
4. 지도에 마커 표시 및 리스트 표시
5. 사용자 인터랙션
   - 마커 탭: 문화재 선택
   - 카테고리 필터: 필터링
   - 당겨서 새로고침: 데이터 갱신

### 데이터 흐름
```
국가유산청 API (XML)
        ↓
HeritageRemoteDataSource (파싱)
        ↓
HeritageRepository (캐싱 전략)
        ↓
Supabase DB (캐시)
        ↓
HeritageController (상태 관리)
        ↓
HomeScreen (UI)
```
