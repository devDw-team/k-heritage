# K-Tour 행사/축제 기능 개발 완료

## 📅 작업 일자
2025년 01월 05일

## 🎯 개발 목표
K-Tour 메인 페이지 내 행사/축제 페이지 개발 및 북마크 기능 통합

## ✅ 완료된 작업

### 1. 행사/축제 기능 전체 구현

#### 1.1 상태 관리 구축
- **FestivalState** (`lib/features/ktour/application/festival_state.dart`)
  - Freezed를 활용한 불변 상태 관리
  - 축제 목록, 필터, 검색, 정렬 상태 관리
  - 북마크 ID 목록 상태 추적

- **FestivalController** (`lib/features/ktour/application/festival_controller.dart`)
  - 축제 데이터 로드 및 페이징 처리
  - 상태별 필터링 (진행중/예정/종료)
  - 지역별, 월별 필터링
  - 검색 기능 구현
  - BookmarkController와 연동한 북마크 토글

#### 1.2 UI 화면 개발

##### 축제 목록 화면 (`festival_list_screen.dart`)
- 상태별 탭 구현 (진행중/예정/종료/전체)
  - 각 탭에 색상 인디케이터 추가
  - 탭별 자동 필터링
- 검색 기능
  - 실시간 검색 with 디바운싱
  - 제목, 장소, 설명 통합 검색
- 필터 기능
  - 지역별 필터 (시/도, 시/군/구)
  - 월별 필터
  - 정렬 옵션 (최신순, 제목순, 수정일순)
- 무한 스크롤 구현
- Pull-to-refresh 지원

##### 축제 상세 화면 (`festival_detail_screen.dart`)
- 이미지 갤러리 (PageView)
- 축제 정보 표시
  - 기간, 장소, 연락처
  - 상세 설명
  - 이용 요금 정보
- 개선된 UI 가시성
  - 상단 버튼들에 반투명 배경 적용
  - 제목 영역 그라데이션 효과
  - 흰색 아이콘으로 가독성 향상
- 공유 기능 (share_plus 패키지)
- 북마크 기능
- 지도 표시 및 길찾기

#### 1.3 위젯 컴포넌트

- **FestivalCardWidget** 
  - 축제 카드 UI (이미지, 제목, 기간, 장소)
  - D-Day 표시
  - 북마크 토글 버튼
  - 종료된 축제 투명도 처리

- **FestivalStatusChip**
  - 진행 상태 칩 (진행중/예정/종료)
  - 상태별 색상 구분

- **FestivalFilterWidget**
  - 바텀시트 형태의 필터 UI
  - 지역, 월, 정렬 옵션 선택

- **FestivalMapView**
  - 축제 위치 지도 표시
  - 마커 및 정보창

### 2. 북마크 기능 통합

#### 2.1 북마크 화면 개선 (`bookmarks_screen.dart`)
- 3개 탭 구성: 관광지 / **행사·축제** / 문화재
- 타입별 북마크 필터링
- 축제 북마크 전용 표시
  - 축제 아이콘 추가
  - 축제 타입 구분

#### 2.2 BookmarkController 확장
- `addBookmarkFromFestival()` 메서드 추가
- `toggleFestivalBookmark()` 메서드 추가
- 축제 타입(contentTypeId: 15) 처리

#### 2.3 TourBookmarkCard 개선
- 축제 타입 북마크 라우팅 처리
- 축제 상세 화면으로 올바른 네비게이션

### 3. API 및 Repository 확장

#### 3.1 KTourRepository 인터페이스
- `searchFestivals()` 메서드 추가
  - 기간별, 지역별, 정렬 옵션 지원
  - 페이징 처리

#### 3.2 KTourRepositoryImpl 구현
- 한국관광공사 행사/축제 API 연동
- 응답 데이터 파싱 및 엔티티 변환

### 4. 라우팅 설정

#### Router 구성 (`app_router.dart`)
```dart
/ktour/festival          → 축제 목록 화면
/ktour/festival/:id      → 축제 상세 화면
```

### 5. 의존성 문제 해결

#### 5.1 share_plus 패키지 추가
- pubspec.yaml에 `share_plus: ^7.2.1` 추가
- 축제 정보 공유 기능 구현

#### 5.2 Hive → SharedPreferences 마이그레이션
- `CourseCacheController` 전체 리팩토링
- Hive Box → SharedPreferences 변환
- 의존성 충돌 해결

## 📊 기술 스택
- **Flutter 3.x** + **Dart 3.x**
- **Riverpod** - 상태 관리
- **Freezed** - 코드 생성 및 불변 객체
- **Go Router** - 라우팅
- **SharedPreferences** - 로컬 캐싱
- **Share Plus** - 공유 기능
