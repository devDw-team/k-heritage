### 1. Tour API 상세 조회 오류 수정
#### 문제
- Tour API 상세 조회 시 "INVALID_REQUEST_PARAMETER_ERROR(contentTypeId)" 오류 발생
- detailCommon1 엔드포인트가 500 에러 반환

#### 해결
- `tour_api_datasource.dart`에서 detailCommon2 엔드포인트 사용으로 변경
- contentTypeId 파라미터 제거 (detailCommon2에서 미지원)
```dart
// detailCommon2 사용 (detailCommon1이 500 오류 반환)
String endpoint = '/detailCommon2';
// detailCommon2에서는 YN 파라미터와 contentTypeId 모두 사용 안 함
```

### 4. SharedPreferences 초기화 오류 수정
#### 문제
- "sharedPreferencesProvider must be initialized on app startup" 오류
- 북마크 메뉴 접근 시 UnimplementedError 발생

#### 해결
- `ktourRepositoryProvider`를 FutureProvider로 변경
- null safety 처리 추가
```dart
final ktourRepositoryProvider = FutureProvider<KTourRepository>((ref) async {
  final tourAPI = ref.watch(tourAPIDataSourceProvider);
  if (_sharedPreferencesInstance == null) {
    await initializeSharedPreferences();
  }
  return KTourRepositoryImpl(
    tourAPI: tourAPI, 
    prefs: _sharedPreferencesInstance!,
  );
});
```

### 5. Dismissible 위젯 오류 수정
#### 문제
- 북마크 삭제 시 "A dismissed Dismissible widget is still part of the tree" 오류

#### 해결
- `confirmDismiss` 콜백 사용으로 변경
- 고유한 ValueKey 생성 (timestamp 포함)
```dart
key: ValueKey('${bookmark.contentId}_${bookmark.bookmarkedAt.millisecondsSinceEpoch}'),
confirmDismiss: (direction) async {
  if (direction == DismissDirection.endToStart) {
    onRemove?.call();
    return true;
  }
  return false;
},
```
