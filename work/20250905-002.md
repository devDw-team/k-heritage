### 1. 축제 상세 정보 API 연동 개선
#### 문제점
- 축제 목록에서는 행사 기간이 표시되나, 상세 화면 진입 시 날짜 정보 손실
- detailCommon2 API가 축제 특화 필드(날짜, 장소 등)를 반환하지 않음

#### 해결 방안
- `FestivalController.getFestivalDetail()` 메서드 수정
- 기존 데이터와 API 응답을 병합하여 정보 보존
```dart
final merged = existing.contentId.isNotEmpty 
  ? existing.copyWith(
      overview: detail.overview ?? existing.overview,
      eventStartDate: existing.eventStartDate ?? detail.eventStartDate,
      eventEndDate: existing.eventEndDate ?? detail.eventEndDate,
      eventPlace: existing.eventPlace ?? detail.eventPlace,
    )
  : detail;
```

### 2. 지도 버튼 가시성 문제 해결
#### 문제점
- 축제 상세 화면에서 "지도에서 보기" 버튼이 표시되지 않음
- eventPlace 필드 존재 여부에만 의존하여 버튼 표시

#### 해결 방안
- 좌표 또는 주소 정보가 있을 때 버튼 섹션 표시
- 지도 및 길찾기 버튼을 독립적인 섹션으로 분리
```dart
if (festival.hasValidCoordinates || festival.fullAddress.isNotEmpty) ...[
  const SizedBox(height: 16),
  Row(
    children: [
      if (festival.hasValidCoordinates)
        Expanded(
          child: OutlinedButton.icon(
            icon: const Icon(Icons.map),
            label: const Text('지도에서 보기'),
            onPressed: () => _navigateToMap(festival),
          ),
        ),
    ],
  ),
],
```

### 4. 라우터 설정 오류 수정
#### 문제점
- `/ktour/festival/calendar` 경로가 `:id` 동적 파라미터로 매칭됨
- "calendar"가 contentId로 해석되는 오류

#### 해결 방안
- Go Router 경로 우선순위 조정
- 특정 경로를 동적 경로보다 먼저 배치
```dart
routes: [
  // 특정 경로를 먼저 매칭
  GoRoute(
    path: 'calendar',
    name: 'festivalCalendar',
    builder: (context, state) => const FestivalCalendarScreen(),
  ),
  // 동적 경로는 나중에 매칭
  GoRoute(
    path: ':id',
    name: 'festivalDetail',
    // ...
  ),
],
```

### 5. 한국어 로케일 초기화
#### 문제점
- 캘린더 뷰 진입 시 LocaleDataException 발생
- 한국어 날짜 포맷팅 데이터 미초기화

#### 해결 방안
- `main.dart`에 로케일 초기화 코드 추가
- intl 패키지의 initializeDateFormatting() 호출
```dart
// Initialize date formatting for Korean locale
await initializeDateFormatting('ko_KR', null);
```
- table_calendar locale 설정을 'ko'로 지정

### 6. 필터 화면 가시성 개선
#### 문제점
- 필터 화면의 선택 옵션 텍스트가 보이지 않음
- 테마 색상 미적용으로 인한 가시성 문제

#### 해결 방안
- FilterChip 및 RadioListTile에 명시적 색상 스타일 적용
- 선택/미선택 상태별 텍스트 색상 구분
```dart
FilterChip(
  label: Text(
    entry.value,
    style: TextStyle(
      color: isSelected 
        ? theme.colorScheme.onPrimary 
        : theme.colorScheme.onSurface,
    ),
  ),
  selectedColor: theme.colorScheme.primary,
  backgroundColor: theme.colorScheme.surfaceContainerHighest,
  checkmarkColor: theme.colorScheme.onPrimary,
  // ...
)
```
