# K-TOUR 여행지 탐색 기능 개발 기록

## 작업 일자
2025년 8월 26일

## 구현 내용

### 1. 여행지 탐색 화면 구현
- **TourExploreScreen**: 지역별/테마별/내 주변 3가지 탭 네비게이션 구현
- 검색바 및 실시간 검색 기능 (디바운싱 적용)
- 결과 카운트 및 정렬 옵션 (제목순/최신순/거리순)
- Pull-to-refresh 및 페이지네이션 지원

### 2. 필터 위젯 구현

#### 2.1 지역별 필터 (AreaFilterWidget)
- 시/도 및 시/군/구 2단계 선택
- 다중 선택 지원
- 선택된 지역 칩 표시
- 스크롤 가능한 칩 리스트

#### 2.2 테마별 필터 (ThemeFilterWidget)
- 관광지 유형별 그리드 뷰
- 아이콘과 레이블 표시
- 다중 선택 지원
- 선택 상태 시각화

#### 2.3 내 주변 필터 (NearbyFilterWidget)
- 위치 권한 요청 플로우
- 반경 선택 슬라이더 (500m ~ 20km)
- 프리셋 버튼 (1km, 3km, 5km, 10km, 20km)
- 위치 서비스 상태 표시

### 3. 상태 관리 구현

#### TourExploreState
```dart
- FilterMode (area, theme, nearby)
- 선택된 필터 옵션들
- 검색 결과 목록
- 페이지네이션 상태
- 위치 정보
- 로딩/에러 상태
```

#### TourExploreController
- 필터 모드 전환
- 지역 코드 로드 및 캐싱
- 검색 실행 (병렬 처리)
- 위치 권한 관리
- 결과 정렬 및 필터링

### 4. 관광 아이템 카드 (TourItemCard)
- 이미지 썸네일 표시
- 제목, 주소, 카테고리 정보
- 거리 정보 (내 주변 모드)
- 전화번호 (있는 경우)
- 탭 이벤트 처리

### 5. 버그 수정 및 개선

#### 5.1 UI 오버플로우 문제 해결
- **AreaFilterWidget**: 텍스트 색상 문제 수정 (배경색과 동일한 색상 문제)
- **ThemeFilterWidget**: Column 오버플로우 해결 (Flexible 위젯 추가, 크기 조정)
- **NearbyFilterWidget**: 컴포넌트 크기 최적화로 오버플로우 해결
- **TourItemCard**: 전화번호 텍스트 오버플로우 수정 (Expanded 위젯 추가)

#### 5.2 위치 권한 문제 해결
- permission_handler에서 Geolocator로 권한 처리 방식 변경
- iOS/Android 네이티브 권한 설정 추가
- 권한 상태별 세분화된 처리 로직
- 마지막 알려진 위치 폴백 지원
- 기본 위치(서울시청) 폴백 지원

#### 5.3 API 데이터 필드명 수정
- TourAttraction 엔티티 필드명 정정
  - addr1 → address1
  - firstimage → firstImage
  - contenttypeid → contentTypeId

### 6. 기술적 구현 세부사항

#### 6.1 병렬 처리
- 지역별/테마별 검색 시 Future.wait()으로 병렬 API 호출
- 성능 향상을 위한 동시 요청 처리

#### 6.2 디바운싱
- 검색어 입력 시 500ms 디바운싱 적용
- 불필요한 API 호출 방지

#### 6.3 권한 처리 개선
- Geolocator.checkPermission() 사용
- LocationPermission enum으로 상태 관리
  - always: 항상 허용
  - whileInUse: 앱 사용 중 허용
  - denied: 거부됨 (재요청 가능)
  - deniedForever: 영구 거부 (설정 필요)

## 기술 스택
- Flutter 3.x
- Riverpod (상태 관리)
- Geolocator (위치 서비스)
- Dio (HTTP 클라이언트)
- Freezed (불변 데이터 모델)
- SharedPreferences (로컬 캐싱)
