# K-Tour 여행정보 화면 개발 계획

## 📋 개발 목표
한국관광공사 Tour API를 활용한 종합 여행정보 화면 개발 (맛집, 숙박, 교통, 쇼핑 정보 통합 제공)

## 🔍 현황 분석

### 기존 구현 현황
- **엔티티**: `TourStay` (숙박) 모델 구현 완료
- **API**: 
  - `searchStay` (숙박 검색) 메서드 구현
  - `getAreaBasedList` (지역기반 조회) 메서드로 음식점/쇼핑 조회 가능
- **콘텐츠 타입**: 
  - 숙박(32), 음식점(39), 쇼핑(38), 레포츠(28)
- **아키텍처**: Clean Architecture 적용

### API 호출 예시
```dart
// 맛집 검색
Future<List<TourRestaurant>> searchRestaurants({
  String? areaCode,
  String? keyword,
  double? mapX,
  double? mapY,
  int? radius,
}) async {
  if (mapX != null && mapY != null) {
    // 위치 기반 검색
    final response = await tourAPI.getLocationBasedList(
      mapX: mapX,
      mapY: mapY,
      radius: radius ?? 1000,
      contentTypeId: '39',
    );
    return response.map((e) => TourRestaurant.fromApiResponse(e)).toList();
  } else {
    // 지역 기반 검색
    final response = await tourAPI.getAreaBasedList(
      areaCode: areaCode,
      contentTypeId: '39',
    );
    return response.map((e) => TourRestaurant.fromApiResponse(e)).toList();
  }
}
```

### 필터 적용 예시
```dart
List<TourRestaurant> applyFilters(
  List<TourRestaurant> restaurants,
  TravelFilter filter,
) {
  var filtered = restaurants;
  
  // 음식 종류 필터
  if (filter.foodType != null) {
    filtered = filtered.where((r) => 
      r.treatMenu?.contains(filter.foodType!) ?? false
    ).toList();
  }
  
  // 주차 가능 필터
  if (filter.hasParking == true) {
    filtered = filtered.where((r) => 
      r.parking != null && r.parking!.isNotEmpty
    ).toList();
  }
  
  // 거리순 정렬
  if (filter.sortBy == SortBy.distance) {
    filtered.sort((a, b) => 
      (a.distance ?? double.infinity)
        .compareTo(b.distance ?? double.infinity)
    );
  }
  
  return filtered;
}
```
